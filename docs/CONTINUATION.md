# Ultimate Pro Personal Hub

## מטרת השלב

מעטפת Electron אישית עם כניסה, פרופיל, מרכז תוכנות, שעון ישראל ומזג אוויר. תוכנת השכר הקיימת נפתחת מתוך האריח שלה. תוכנת ההכנסות וההוצאות והיומן האישי פעילים; כספת הקבצים עדיין בתכנון.

## מבנה

- `src/renderer/apps/registry.js`: רשימת התוכנות, סטטוס ויעד פתיחה.
- `src/renderer/apps/salary/`: נקודת תיעוד לחיבור תוכנת השכר הישנה.
- `src/renderer/apps/finance/finance.js`: מסך תנועות, חשבונות, תקציבים, תנועות קבועות, סינון וייצוא/שחזור.
- `src/renderer/apps/finance/finance-model.js`: חישובי חודש, יתרות, החזרים, העברות, תשלומים ותקציבים.
- `src/renderer/apps/calendar/`: לוח חודשי, agenda יומית ויצירה/עריכה/מחיקה של אירועים.
- `src/renderer/apps/vault/`: שלד עתידי לכספת קבצים.
- `src/renderer/shared/profile.js`: בדיקת פרופיל וחישוב גיל מתאריך לידה.
- `src/renderer/shared/clock.js`: הצגת תאריך ושעה לפי `Asia/Jerusalem`.
- `src/main/services/profile-store.js`: הצפנה ושמירה מקומית של הפרופיל דרך Electron `safeStorage`.
- `src/main/services/finance-store.js`: הצפנה ושמירת נתוני הכספים בקובץ מקומי נפרד.
- `src/main/services/weather-service.js`: קריאת Open-Meteo ללא מפתח ונרמול תנאי מזג אוויר.
- `main.js` ו־`preload.js`: גבול Electron וערוצי IPC מורשים בלבד.
- `tests/`: בדיקות שכר, מודל הכספים, גיבוי, פרופיל ומזג אוויר.

## הפעלה ובדיקות

```powershell
npm install
npm test
npm start
```

יש להיכנס עם הקוד `327806279`. ניתן להשלים שם ותאריך לידה בהגדרות המרכז; תעודת זהות, דוא״ל וטלפון רשותיים. שמירת פרופיל מוצפנת דרך מערכת ההפעלה. ללא Electron לא ניתן להשלים שמירה מוצפנת.

נתוני הכנסות והוצאות נשמרים בנפרד ובצורה מוצפנת דרך `safeStorage`. גיבוי JSON כולל רק את מודול הכספים; שחזור דורש אישור ואינו מחליף נתוני שכר או פרופיל. CSV מיועד לייצוא תנועות בחודש שנבחר.

## מזג אוויר

מזג האוויר נשאב מ־Open-Meteo בקואורדינטות עפולה, ללא מפתח או אימות, ומתעדכן כל 15 דקות. כשל רשת מציג הודעה רגועה ואייקון fallback. ה־API נקרא בתהליך הראשי.

כרטיסי “טיפ להיום” ו“הידעת?” משתמשים ב־Advice Slip וב־Useless Facts. גם הם נקראים בתהליך הראשי, ללא API key, עם timeout ותוכן fallback.

## פרטיות ומגבלות ידועות

- קוד הכניסה הקבוע הוא שער נוחות מקומי, לא אימות אבטחה חזק.
- תעודת זהות, טלפון, דוא״ל ותאריך לידה נשמרים בפרופיל המוצפן המקומי. הם אינם נשלחים לשירות מזג האוויר.
- קיצורי דוא״ל ו־WhatsApp משתמשים בפרטים האישיים ופותחים יישום חיצוני רק אחרי לחיצה. אין שליחה אוטומטית.
- נתוני השכר הישנים ממשיכים להיטען דרך מנגנון האפליקציה הקיימת. לא בוצעה העברה שלהם למבנה הנתונים החדש.
- תוכנת הכספים אינה מתחברת לבנק ואינה מייבאת דפי בנק אוטומטית. תנועות קבועות נוצרות כשפותחים חודש; עריכת מופע חודשי לא משנה את הכלל החוזר.
- חשבון שנרשם בו מידע אינו ניתן למחיקה כרגע. תשלומים בפריסה נשמרים כתנועות נפרדות; שינוי/מחיקה של אחד מהם מתייחס לקבוצת התשלומים.
- מימוש C# לא נכלל: לא הותקן SDK של .NET, והיישום נשאר Electron כדי לשמור על כלי השכר שעובד.
- הממשק מיועד לחלון מחשב; אין יעד נפרד להתאמת טלפונים.

## המשך עבודה

1. לאמת בזמן אמת שה־APIs החינמיים זמינים ברשת היעד; במקרה כשל, לוודא שה־fallback נשאר מוצג ללא שגיאה טכנית.
2. לבדוק ב־Electron תנועה מכל סוג, העברה, החזר, תקציב, תשלום בפריסה, כלל חוזר, גיבוי ושחזור.
3. להוסיף אפשרות לנהל ולמחוק כללי תנועה קבועה ולערוך פרטי חשבון, עם בדיקות ייעודיות.
4. להוסיף בהמשך תזכורות מערכת ויומן חוזר, ולתכנן את כספת הקבצים בנפרד לפני מימוש.
